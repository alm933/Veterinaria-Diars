# Veterinaria DIARS — prototipo visual

Maqueta inicial estática en HTML, CSS y JavaScript para conversar sobre la dirección visual del proyecto.

## Ver en el navegador

Abre `index.html` directamente, o sirve esta carpeta con cualquier servidor estático local.

## Contenido

- Página de inicio adaptable a móvil y escritorio
- Navegación móvil
- Secciones de servicios, equipo y contacto
- Sin backend ni persistencia; no recopila datos

Las ilustraciones de mascotas son emoji de marcador provisional. Las tipografías se cargan desde Google Fonts; con conexión limitada se usarán las tipografías de respaldo del navegador.
